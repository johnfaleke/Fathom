01 / THE SIGNAL

Git tells you what moved.
Fathom tells you what it means.

Modern development produces change faster than humans can track it. Fathom takes a reading of the repository and turns scattered artifacts into a shared, inspectable picture of the work.

01

Evidence before opinion

Deterministic checks inspect your files, manifests, environment examples, and Git state. Every finding points back to what was observed.

See the checks →
02

Model before meaning

Scan turns observations into evidence-backed claims about your stack, files, dependencies, and project reality.

Explore the model →
03

AI only when invited

Set up a provider once, keep keys outside the project, and choose exactly when filtered context can leave the machine.

Install the CLI on your machine, then run it from any project workspace. Initialize each project once; its state stays local in `.fathom/`.

WORKSPACE LOOP

Scan first. Reason second.

fathom initRun once per workspace to create local state, config, events, and `.env.example`.
fathom scanBuild `.fathom/model.json` from files, manifests, observations, and claims.
fathom checkFind missing wiring locally and exit nonzero when warnings need attention.
fathom statusCombine Work State, findings, and changed files in one view.
fathom diffSummarize Git changes by project area.
fathom mcpLaunch the Model Context Protocol stdio server for AI coding agents.

DETERMINISTIC CHECKS

Checks you can explain to a teammate.

ENV
config.env-var-missing

Finds `process.env.X` usage without a matching entry in `.env.example`.

DEP
deps.undeclared-import

Finds imported packages missing from the project manifest.

API
Public check interface

Add a check by implementing `Check.run(ctx)` and returning evidence-backed findings.

04 / BUILD ON IT

Open by design.
Useful before it is clever.

The CLI is the first interface. The versioned Project Model, Work State schema, and clean SDK contracts make Fathom ready for CI pipelines, scripts, and coding agents.

Read the source ↗Open an issue ↗
01CI & Script Ready

Deterministic exit codes (0 = clean, 1 = error/consent, 2 = warnings) and machine-readable --json on all commands.

02Multi-Profile AI & Local Endpoints

Configure named profiles for OpenAI or local OpenAI-compatible endpoints (Ollama, vLLM, LocalAI) with keys kept strictly in environment variables.

03Safe Redaction Engine

Context filtering automatically excludes sensitive files, private keys, and binaries, and redacts embedded secrets before transmission.

04Agent & Schema Seams

Consume .fathom/model.json and llms.txt directly from coding agents, IDE extensions, or custom check plugins.
