01 / WORKSPACE LOOP

Reconstruct first. Understand second.

Every Fathom command runs locally by default, supports universal --json for scripting, and adheres to strict CI exit codes.

fathom status
Automatic project sounding Reconstructs current objective from Git, groups files by software domain, lists completed items and open findings.
fathom explain <id>
Inspect deterministic evidence Shows exact coordinates, AST lines, manifest observations, risk level, and provenance for any finding (e.g. fathom explain FND-01).
fathom check
Verify project integrity Finds missing env variables, undeclared packages, and broken wiring. Supports --format [terminal|github|markdown], --fail-on, and --max-attention.
fathom diff
Semantic change summary Summarizes Git changes categorized by project domain (API, Database, Logic, Config, Tests).
fathom mcp
Model Context Protocol stdio server Connects AI coding assistants (Cursor, Claude Desktop, Antigravity) to live Fathom soundings and tools via MCP.
fathom scan
Build Project Model Extracts deterministic observations, packages, files, git state, and builds .fathom/model.json.
fathom init
Initialize workspace state Creates local .fathom/ directory, configuration, event history, and sample baseline.
fathom setup
Provider & Profile Manager Configures named LLM profiles (OpenAI, Ollama, LocalAI) without checking keys into Git.

02 / DETERMINISTIC CHECKS & CI GATING

Checks you can explain to a teammate.

Zero hallucinations in verification. Fathom checks run with deterministic rules, produce machine-readable outputs, and integrate directly into GitHub Actions workflows.

ENV
config.env-var-missing

Scans code for process.env.VARIABLE references and flags variables missing from .env.example with exact line coordinates.

DEP
deps.undeclared-import

Finds third-party package imports in source code that are missing from package.json dependencies or manifests.

CI
GitHub Actions Annotations

Run fathom check --format github to emit native workflow annotations (::warning, ::error) right on pull request diffs.

EXIT
Predictable Exit Codes & Gating

0 = clean sounding, 1 = fatal error / unconsented external transmission, 2 = findings need attention. Gate merges with --max-attention 0.

03 / PROJECT MODEL

Observations become claims.

The Project Model provides a structured, versioned representation of your codebase so tooling and agents can reason about reality rather than raw file dumps.

"schemaVersion""0.3.0"
"project.files"184 tracked files
"project.stack"[ "TypeScript", "Node.js" ]
"observations"[ FilePresence, ManifestDependency, EnvVarRef ]
"claims"[ StackClaim, WiringClaim, CompletenessClaim ]
"evidence"[ Exact file paths, line ranges, commit hashes ]

Stored locally in .fathom/model.json. You can query it via fathom status --json, inspect it in scripts, or pass it to agents using llms.txt.

04 / SAFE AI & MCP AGENT SERVER

Useful when invited. Bounded by default.

Fathom bridges the gap between raw codebase complexity and AI coding assistants with zero hallucinated state and ironclad privacy boundaries.

MCP
Model Context Protocol stdio server

Run fathom mcp to connect Claude Desktop, Cursor, or Antigravity to Fathom tools (fathom_status, fathom_check, fathom_scan) and resources.

SEC
Automatic Redaction Engine

Context filtering automatically strips API tokens, private keys, .env values, and binary assets before transmission.

PRO
Named Provider Profiles

Configure OpenAI, Ollama, vLLM, or LocalAI endpoints locally with fathom setup. Credentials never enter project git history.

EVD
Evidence-Attached Explanations

Running fathom check --ai provides structured reasoning strictly anchored to observed deterministic findings.
